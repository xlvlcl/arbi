ARBI v29 — naprawa blokady źródła + bezpośrednie buki

CO ZMIENIONO
1. DobryBuk nie jest już pojedynczym punktem awarii. Jeśli go zablokuje Cloudflare, skaner kontynuuje pracę.
2. Bezpośredni skan publicznych stron bukmacherów działa przy KAŻDYM cyklu, także gdy FORCE_FAST_SCAN=1.
3. Priorytetowe źródła: Betclic, Fortuna, STS, Superbet, Betfan, Forbet; dodatkowo LVBet, ETOTO, Fuksiarz, TotalBet, Betters, LeBull, AdmiralBet, BetSport, ComeOn, PZBuk.
4. Parser potrafi czytać zdarzenia, gdy nazwa meczu i kursy są w różnych elementach karty strony.
5. Kursy znalezione przez przeglądarkę są ponownie sprawdzane przed alertem.
6. Gdy wszystkie źródła chwilowo zawiodą, strona nie znika i workflow nie musi być czerwony. Ostatnie poprawne okazje są zachowane i wyraźnie oznaczone jako STARE DANE.
7. Zewnętrzny trigger co ~2 minuty jest traktowany jako główny harmonogram. Heartbeat GitHuba jest tylko ręcznym testem, więc nie dubluje Twojego zewnętrznego wyzwalacza.
8. Watchdog co 5 minut pozostaje jako awaryjne zabezpieczenie i uruchomi skaner, gdy dane przestaną się aktualizować.

JAK WGRAC
1. Rozpakuj ZIP.
2. W repozytorium arbi wgraj CAŁĄ zawartość paczki do katalogu głównego, zastępując stare pliki.
3. Koniecznie podmień folder .github/workflows.
4. Commit changes do main.
5. Wejdź Actions > Surebet Scanner > Run workflow > main i uruchom RAZ ręcznie.
6. Nazwa joba powinna zawierać: "Skan, status i publikacja — v29".
7. Nie uruchamiaj ręcznie wszystkich trzech workflowów naraz.

TWOJ UKLAD
- Zewnętrzna strona/skrypt: wyzwala Surebet Scanner mniej więcej co 2 minuty.
- Surebet Scanner: pobiera kursy i zapisuje latest.json.
- Surebet Freshness Watchdog: awaryjnie uruchamia Scanner, jeśli dane są stare.
- Surebet 2-Minute Heartbeat: tylko ręczny test; nie ma już automatycznego crona.

WAZNE
Nie ma legalnego sposobu zagwarantowania, że każda publiczna strona bukmachera zawsze przepuści serwery GitHub Actions. v29 nie omija CAPTCHA ani zabezpieczeń. Zamiast tego używa wielu niezależnych publicznych źródeł i bezpiecznie degraduje się, gdy część z nich jest niedostępna.
