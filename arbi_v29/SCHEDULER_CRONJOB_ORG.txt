ZEWNETRZNY SCHEDULER NIE JEST JUZ WYMAGANY

Paczka zawiera .github/workflows/heartbeat.yml. Ten workflow uruchamia Surebet Scanner co okolo 2 minuty w ramach kolejnych 15-minutowych okien.

Po wgraniu plikow:
1. GitHub > Actions > Surebet Scanner > Run workflow > main (raz, aby wdrozyc strone).
2. GitHub > Actions > Surebet 2-Minute Heartbeat > Run workflow > main (opcjonalnie raz od razu; potem dziala z harmonogramu).
3. Nie dodawaj tokena GitHub do kodu ani do strony. Heartbeat uzywa bezpiecznego github.token dostepnego tylko wewnatrz Actions.

cron-job.org moze pozostac jako dodatkowy fallback, ale nie jest potrzebny do podstawowego odswiezania.
