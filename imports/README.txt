TU WRZUCASZ RĘCZNIE ZAPISANE PLIKI HTML Z DOBRYBUK.

Najprościej:
1. Otwórz https://dobrybuk.pl/kursy w zwykłej przeglądarce.
2. Ustaw sport i rynek, który chcesz zaimportować.
3. Ctrl+S -> zapisz jako "Strona internetowa, kompletna" (.html).
4. Na GitHubie wejdź do folderu imports/ i wrzuć zapisany plik .html.
5. Commit changes.
6. Workflow "DobryBuk Import + Publish" uruchomi się sam i zaktualizuje stronę.

Możesz wrzucić kilka plików HTML naraz, np. osobno piłka nożna, tenis, koszykówka itd.
Dobrze jest nazwać plik ze sportem, np.:
  pilka-nozna__1x2.html
  tenis__winner.html
  koszykowka__1x2.html

Importer NIE pobiera DobryBuk sam i NIE omija Cloudflare.
